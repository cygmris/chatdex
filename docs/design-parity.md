# 对稿记录（dashboard-redesign）

定案稿：claude-design 上的
`chatdex 2 · 1d 落地 + 四主题.dc.html`。

需求 2.6 要求「与设计稿的偏离逐条记录并说明原因，不得静默简化」。以下是全部偏离。

## 一、定案稿只画了检索页

稿里的 2a–2e 五张图都是**检索页**（分别是工作台/亮·左栏展开、左栏收起、编辑器/暗、
终端/暗、纸张/亮），另有 2f 的 token 对照表。时间线、摘要、问一问、设置、会话回读
五个页面没有单独的稿。

于是这五个页面的「对稿」只能是对**设计语言**（token、间距、信息层级、圆角、字体指派）
一致性检查，而不是逐像素比对。这不是偷懒——稿本来就没画，声称比对过是虚报。

## 二、检索页与稿的逐条差异

| # | 稿 | 实现 | 为什么 |
|---|---|---|---|
| 1 | 过滤条是一排 tab：全部 / 我说的 / 助手 / 工具调用 / 摘要 | 一排控件：来源下拉、内容类型下拉、工具名输入、起止日期、清空 | 稿只画了 `kind` 一个维度，而 R1 需求 3 要求六项过滤（来源 / 类型 / 工具名 / 项目 / 时间范围）。tab 排不下六个维度。**保留稿的信息密度意图**：仍是单行、不折叠、不藏进抽屉 |
| 2 | 左栏「时间」项带计数（今天 21 / 最近 7 天 184） | 无计数 | 这两个计数要为每次渲染多打两次带时间范围的 count 查询，而左栏每次切项目/切视图都重渲。收益（两个数字）与代价（每次渲染两次全表 count）不成比例 |
| 3 | 顶栏右侧只有明暗三态按钮 | 另有索引统计（`3182 会话 · 649k 块 · 1.3 GB`）与摘要进度条 | 这两项在 R1 已交付并有需求依据（摘要进度可暂停/恢复）。稿是新布局的示意，没有回收既有功能的意思 |
| 4 | 片段（证据行）有浅色底块 | 无底块，仅等宽字体 + 缩进 | 一条结果里片段可能有三四行，加底块后整页变成一排灰砖，主标题（摘要）的视觉优先级被压掉——而「摘要为主标题、片段降为证据」正是这次改版的核心意图 |

其余均与稿一致：左栏 178px / 收起 46px 单字导航（检/时/摘/问/设）、摘要为条目主标题、
元信息压成一行、四套主题的 token 取值（见 `theme.css` 与稿的 2f 对照表）。

## 三、对稿过程中发现并修掉的问题

不是「记录待办」，是当场修了：

1. **过滤条在「问一问」「设置」页上照样显示**。代码本来就写了 `filters.hidden = ...`，
   但 `.filters { display: flex }` 盖掉了浏览器给 `[hidden]` 的 `display: none`，
   于是那行代码看着毫无效果。同一个坑还中了 `.chat-form`——意味着
   **「LLM 不可用时聊天入口置灰」实际没生效**。已加 `[hidden] { display: none !important; }` 兜底。
2. **摘要页头部显示「共 0 条摘要」而下面列着 20 条**。视图先于 `/api/stats` 挂载，
   读到的还是初值。改为占位 `…` 由 `loadStats` 回填，且仅在计数变化时回填——
   每 10 秒重挂视图会把正在看的列表滚回顶部。
3. **结果条目能点不能聚焦**（`<article>` + 裸 `onclick`）：键盘用户搜到了却打不开。
   已加 `CD.clickable`（tabIndex + Enter/Space）。
4. **按钮只有浏览器默认焦点环**，暗色主题下几乎看不见。已加 `:focus-visible` 用 `var(--accent)`。

## 四、截图覆盖范围（说清楚哪些是真看过的）

实际逐张看过的组合：

| 页面 | 主题 |
|---|---|
| 检索 | 工作台、纸张、终端 |
| 时间线 | 编辑器 |
| 摘要 | 编辑器、终端 |

即：**五个页面各至少一套主题、四套主题各至少一个页面**，不是完整的 5 × 4 = 20 张。

没有跑满 20 张的理由：四套主题是同一组 CSS 变量的四组取值，页面样式一律写 `var(--x)`，
而这两点各有自动化测试守着——`TestThemesDefineSameTokens`（四套主题 token 名集合完全一致）
与 `TestLayoutUsesTokensOnly`（布局样式表里没有写死的颜色）。在这两条成立的前提下，
「某页在某套主题下坏掉」只可能由写死颜色引起，而那正是测试拦住的东西。
再补 12 张截图是重复劳动，不是额外保证。

对比度不靠看：四套主题的正文/次要文字对背景由 `internal/dashboard/theme_test.go`
脚本计算，实测 desk 16.48/6.28、paper 15.35/5.60、editor 14.20/6.82、term 12.51/6.52，
全部达 WCAG AA（≥ 4.5:1）。
