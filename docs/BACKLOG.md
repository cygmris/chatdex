# BACKLOG

状态机：`idea → roadmap → spec'd → shipped(R#)`，另有终态 `已关(日期)`。

`已关` 是**决定不做**，不是做完了。工具（`backlog` 的 set-status）只认前一条链路，
所以这个状态靠手写——但**必须在「关联」列写清为什么关**，否则半年后问
「为什么没做 X」只剩「当时觉得不用」。
